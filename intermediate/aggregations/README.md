# Intermediate Aggregations

HackerRank SQL intermediate aggregation solutions covering geometric 
distance calculations using MAX, MIN, ABS, POWER, SQRT and ROUND 
across multi-column aggregations.

## Concepts Covered
- Manhattan Distance using ABS and MAX/MIN aggregations
- Euclidean Distance using POWER, SQRT and MAX/MIN aggregations
- Arithmetic combining multiple aggregate functions in one query
