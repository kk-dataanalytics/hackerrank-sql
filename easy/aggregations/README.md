# Easy Aggregations

HackerRank SQL easy aggregation solutions practising COUNT, SUM, AVG, 
MAX, MIN, ROUND, TRUNCATE, CEIL and CONCAT across real business scenarios.

## Concepts Covered
- COUNT with WHERE filter
- SUM with conditional filtering
- AVG with and without filters
- ROUND, TRUNCATE and CEIL for decimal formatting
- MAX and MIN with range filters
- Arithmetic on aggregate functions
- Subqueries inside WHERE to find matching rows
- REPLACE within aggregations
- CONCAT to format multiple aggregated values
